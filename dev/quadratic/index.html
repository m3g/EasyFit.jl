Quadratic fit

Use the fitquad (or fitquadratic) function:

using EasyFit, Plots, Random
Random.seed!(1)

x = sort(rand(10))
y = x .^ 2 .+ 0.1 * rand(10)

fit = fitquad(x, y)

plot!(fit.x, fit.y, label="fit", linewidth=2)
