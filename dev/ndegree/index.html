N-th degree polynomial fit

Use the fitndgr function, passing the desired polynomial degree as the third argument:

using EasyFit, Plots, Random
Random.seed!(1)

x = sort(rand(10))
y = @. 1 + 2x + 3x^2 + 4x^3 + 6x^4

fit = fitndgr(x, y, 4)
